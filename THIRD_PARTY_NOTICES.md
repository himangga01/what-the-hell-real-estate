- 사용 버전: `v0.7.18`
- 저작권: Copyright (c) 2025-2026 Edward Kim
- 라이선스: MIT License
- 공식 저장소: <https://github.com/edwardkim/rhwp>
- 공식 릴리스: <https://github.com/edwardkim/rhwp/releases/tag/v0.7.18>
- 공식 라이선스: <https://github.com/edwardkim/rhwp/blob/v0.7.18/LICENSE>
- 이 프로젝트의 사용 범위: 조사 단계에서 HWP 원문의 텍스트·Markdown을 임시 추출하고
  입력·도구·출력 SHA-256을 기록하는 CLI

이 프로젝트는 `rhwp` 실행 파일을 저장소에 재배포하지 않는다. 실행 시 공식 GitHub
릴리스에서 고정 버전을 임시 다운로드하고 `SHA256SUMS.txt`로 archive를 검증한 뒤 삭제한다.

`rhwp`를 사용한 추출 성공은 정부 원문의 저작권·공개·RAG 권리, 법적 효력, 세무 규칙 또는
공간 경계를 승인한다는 의미가 아니다.
