# 세금 분석 지원 행렬

**목적**: v1이 결정론적으로 계산할 사례와 멈춰야 할 사례를 명시한다.

**주의**: `설계 목표`는 공식 원문·규칙 카드·골든 사례 검수가 끝났다는 뜻이 아니다.
검수 전 항목은 공개 계산에 사용하지 않는다.

## 상태 정의

- `설계 목표`: v1 구현·검수 대상
- `부분 지원`: 원칙·입력·공식 확인 경로와 개략 범위만 제공
- `미지원`: `UNSUPPORTED` 또는 `REQUIRES_OFFICIAL_CHECK`로 종료
- `게시 완료`: 공식 근거, 규칙 해시, 검수 승인과 골든 사례가 모두 있는 상태

## 취득 단계

| 사례 | v1 상태 | 출력 범위 | 필수 선행 검수 |
|---|---|---|---|
| 개인의 국내 주택 일반 유상취득 | 설계 목표 | 취득세 본세와 부가세목 분리 추정 | 세율·면적·가액 경계 |
| 세목별 주택 수 중과 | 설계 목표 | 취득세 산정 주택 수 파생 및 중과 여부 | 주택·입주권·분양권 포함 규칙 |
| 일시적 2주택 | 설계 목표 | 처분기한·지역·취득 순서 조건 | 경과규정과 예외 |
| 생애최초 주택 취득 감면 | 설계 목표 | 감면 후보와 추징 위험 조건 | 소득·가액·거주·처분 요건 |
| 상속·증여 취득 | 부분 지원 | 취득 원인별 원칙과 필요 입력 | 과세표준·특례 전수 |
| 법인·비거주자·외국법인 취득 | 미지원 | 전문 확인 경로 | 별도 지원 계획 |
| 농지·상가·공장·복합용도 | 미지원 | 자산 유형 확인 경로 | 비주택 규칙팩 |
| 부담부증여·명의신탁·신탁 | 미지원 | 위험 고지 | 전문 검토 |

취득 입력에는 취득 원인, 계약·계약금·잔금·등기·취득일, 거래가액,
시가표준액, 전용면적, 주소·PNU, 실제 용도, 지분, 생애 주택 소유 이력,
세대 보유 이력, 종전 주택 처분일과 임차인 만료일이 필요할 수 있다.

## 세목별 주택 수

사용자에게 하나의 `주택 수` 숫자를 받아 모든 세금에 재사용하지 않는다.

```text
입력 사실과 보유 이력
  ├─ 취득세 규칙 버전       → home_count.acquisition
  ├─ 양도소득세 규칙 버전   → home_count.capital_gains
  └─ 종합부동산세 규칙 버전 → home_count.comprehensive_holding_tax
```

각 파생 사실은 포함·제외한 부동산, 기준일, 규칙 ID와 근거를 반환한다.

## 계산 결과 표시

총액 하나만 표시하지 않는다.

- 본세
- 지방교육세·지방소득세·농어촌특별세·도시지역분 등 부가세목
- 공제·감면
- 반올림·절사
- 개략값을 사용한 입력
- 포함하지 않은 세목·비용
- 납부·신고기한은 공식 확인 필요 항목

금액을 확정할 수 없으면 최소·최대 범위와 범위를 만든 입력만 보여준다.

## 게시 게이트

각 `설계 목표` 항목은 다음을 모두 충족해야 `게시 완료`가 된다.

1. 법령·시행령·시행규칙·공식 안내의 역할별 원문 연결
2. 발행·공포·시행·종료·경과 날짜 확인
3. 규칙 JSON Schema 검증과 내용 해시
4. 금액·세율 경계의 `-1/당일/+1` 골든 사례
5. 날짜의 전일·당일·익일 골든 사례
6. 포함·제외·억제된 규칙과 인용 추적 검수
7. 세무 검토자 승인
